# API Documentation

Base URL (local): `http://127.0.0.1:8000`. Interactive docs auto-generated by FastAPI are available
at `/docs` (Swagger UI) and `/redoc` while the backend is running.

Authentication: all endpoints except `POST /auth/login`, `GET /`, and `GET /health` require an
`Authorization: Bearer <token>` header. Obtain a token via `POST /auth/login`.

## Authentication — `/auth`

| Method | Path | Role required | Body | Response |
|---|---|---|---|---|
| POST | `/auth/login` | none | form-encoded `username`, `password` | `Token` (`access_token`, `role`, `username`) |
| POST | `/auth/logout` | any authenticated user | — | `{"detail": "..."}` (stateless — client discards token) |
| GET | `/auth/me` | any authenticated user | — | `UserOut` |
| POST | `/auth/users` | administrator | `UserCreate` (`username`, `email`, `password`, `role`) | `UserOut` (201) |
| GET | `/auth/users` | administrator | — | `list[UserOut]` |

## Security Events — `/events`

| Method | Path | Role required | Body | Response |
|---|---|---|---|---|
| POST | `/events/upload` | administrator, security_analyst | multipart `file` (CSV) | `IngestionResult` (`total_rows`, `valid_rows`, `invalid_rows`, `errors[]`) |
| GET | `/events` | any authenticated user | query: `skip`, `limit`, `source_ip` | `list[SecurityEventOut]` |
| GET | `/events/{event_id}` | any authenticated user | — | `SecurityEventOut` |

Required CSV columns: `timestamp, source_ip, destination_ip, user_id, login_attempts,
failed_login_attempts, request_frequency, session_duration, data_transfer_volume, access_type,
device_information`. Optional: `geo_location, attack_label`.

## Threat Detection — `/detection`

| Method | Path | Role required | Body | Response |
|---|---|---|---|---|
| POST | `/detection/train` | administrator | — | Full evaluation results JSON (accuracy/precision/recall/F1/confusion matrix/latency for Random Forest; score separation stats for Isolation Forest) |
| POST | `/detection/run` | administrator, security_analyst | — | `DetectionRunSummary` (`events_processed`, `alerts_generated`, `severity_breakdown`). Returns `409` if models are not yet trained. |
| GET | `/detection/evaluation` | any authenticated user | — | Last saved evaluation results JSON. `404` if models have never been trained. |
| GET | `/detection/results` | any authenticated user | query: `skip`, `limit` | `list[DetectionResultOut]` |

## Alert Management — `/alerts`

| Method | Path | Role required | Body | Response |
|---|---|---|---|---|
| GET | `/alerts` | any authenticated user | query: `severity`, `status`, `search` | `list[AlertOut]` |
| GET | `/alerts/{alert_id}` | any authenticated user | — | `AlertOut` |
| POST | `/alerts/{alert_id}/acknowledge` | administrator, security_analyst | — | `AlertOut` (status → `acknowledged`) |
| POST | `/alerts/{alert_id}/escalate` | administrator, security_analyst | — | `IncidentOut` (creates a new incident; `400` if already escalated) |

## Incident Management — `/incidents`

| Method | Path | Role required | Body | Response |
|---|---|---|---|---|
| GET | `/incidents` | any authenticated user | query: `status_filter` | `list[IncidentOut]` |
| GET | `/incidents/{incident_id}` | any authenticated user | — | `IncidentOut` |
| PUT | `/incidents/{incident_id}/status` | administrator, security_analyst | `IncidentStatusUpdate` (`status`, `resolution_notes?`) | `IncidentOut` |
| POST | `/incidents/{incident_id}/notes` | administrator, security_analyst | `IncidentNoteCreate` (`note`) | `IncidentOut` (with appended note) |

## Reporting — `/reports`

| Method | Path | Role required | Body | Response |
|---|---|---|---|---|
| GET | `/reports/summary` | any authenticated user | — | `ReportSummary` (live counts + last evaluation metrics) |
| GET | `/reports/export/csv` | any authenticated user | — | `text/csv` file download of all alerts |
| GET | `/reports/export/pdf` | any authenticated user | — | `application/pdf` summary report |
| GET | `/reports/audit` | administrator | query: `skip`, `limit` | `list[AuditLogOut]` |

## Error Responses
Standard FastAPI/Pydantic error shape: `{"detail": "..."}`. Common status codes used:
`400` (bad request / validation), `401` (missing/invalid/expired token), `403` (role not permitted),
`404` (resource not found), `409` (detection models not trained yet), `500` (unexpected server
error, e.g. model training failure).
